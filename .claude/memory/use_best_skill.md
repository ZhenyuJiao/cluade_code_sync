做事前先主动搜索并安装最优的 skill，而不是自己硬做或用默认方式。

**Why:** 用户认为 skill 存在的意义就是做得更好，应该优先用 skill 而不是靠自己。

**How to apply:**
- 接到任务后，先用 find-skills 搜索相关 skill
- 评估哪个 skill 最匹配当前任务
- 安装并用它来实际干活，而不是走形式
- 如果没有合适的 skill，再靠自己

## 二、案例收集模板

每条案例收集时按这个结构整理:

```markdown
## [案例标题]

来源: [链接]
发现日期: 2026-XX-XX
可信度: ⭐⭐⭐ (高/中/低，根据是否有截图、收入证明等)

### 基本信息
- 分类: 写作/设计/视频/办公/翻译/其他
- 难度: 入门/进阶/高阶
- 时间投入: 
- 收入范围: 
- 所需工具: 

### 痛点
[这个人/这群人遇到了什么问题？为什么需要这个服务？]

### 解决方案
[他是怎么用 AI 解决的？具体怎么操作的？]

### 结果
[赚了多少钱？花了多少时间？]

### 步骤
1. 
2. 
3. 

### 可信度判断
- [ ] 有收入截图
- [ ] 有具体步骤，不是笼统描述
- [ ] 有案例/作品展示
- [ ] 不是卖课的
- [ ] 评论区有真实互动
```

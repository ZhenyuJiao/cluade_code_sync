# UI/交互设计参考

> 产品经理 | 持续更新 | 2026-05-10

---

## 一、设计原则

1. **降低认知门槛** — 用户是普通人，界面要像小红书一样简单直观，不要复杂 UI
2. **手机优先** — 目标用户主要用手机刷，所有设计先适配移动端
3. **信任感** — 绿色主色调传递"安全、可靠、赚钱"的感觉，不搞花哨
4. **内容为王** — 界面是配角，案例内容才是主角，设计不要喧宾夺主

---

## 二、视觉风格

```
风格: 简洁、温暖、可信、亲民

配色:
  - 主色: #10b981 (翡翠绿) — 代表"赚钱、成长"
  - 辅助色: #f59e0b (琥珀) — 用于收入/亮点高亮
  - 背景: #f9fafb (极浅灰) — 舒适不刺眼
  - 卡片: #ffffff (白) — 清晰分层
  - 文字: #111827 (深灰近黑) — 高可读性

字体: -apple-system, 'Noto Sans SC', sans-serif
      系统原生字体，加载快、中文显示好

圆角: 12px (大圆角，亲切感)
阴影: 轻微柔和，不要投影过重
```

## 四、移动端适配要点

| 场景 | 处理方式 |
|------|---------|
| 导航 | 汉堡菜单展开，不用 tab bar（内容站不需要频繁切换） |
| 筛选 | 横向滚动标签，不要下拉选择 |
| 卡片 | 全宽卡片，大字号，大点击区域 |
| 详情页 | 步骤字体 ≥ 16px，防止 iOS 缩放 |
| 弹窗 | 全屏弹窗，从底部滑入 |
| CTA | 固定底部操作栏（分享/收藏） |

## 五、交互细节

### 5.1 微交互

```
- 案例卡片: hover 时微微上浮 + 阴影加深
- 筛选切换: 卡片淡入淡出
- 步骤列表: 灰色变彩色，完成感
- 收入数字: 加粗 + 琥珀色高亮
- 加载中: 骨架屏（灰色块闪烁），不要转圈
```

### 5.2 文案风格

```
- 用"你"，不用"用户"
- 短句，不用长句
- 数字加粗: "一单 50-200 元" 
- 动词开头: "注册 Claude 账号" 不是 "首先需要注册一个 Claude 账号"
- 避免: 成语、术语、英文缩写
```

### 5.3 空状态/错误状态

```
无搜索结果:
  "没找到相关案例 🙁 试试换个关键词"
  显示 [看看其他分类 →]

页面加载失败:
  "加载失败了，刷新一下试试"
  显示 [重新加载] 按钮

案例不存在:
  "这个案例可能已经被删除了"
  显示 [返回案例库] 按钮
```
